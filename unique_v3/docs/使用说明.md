# UniqueV3 算子使用说明

---

## 环境要求

| 依赖项 | 版本要求 |
|---|---|
| CANN Toolkit | ≥ 8.0（已安装并配置 `ASCEND_HOME_PATH`） |
| Python | 3.8 ~ 3.10 |
| PyTorch | ≥ 2.1 |
| torch_npu | 与 PyTorch 版本匹配 |
| CMake | ≥ 3.19 |
| GCC | ≥ 7.3 |

确保以下环境变量已正确设置：

```bash
# CANN 环境变量（通常由 set_env.sh 自动设置）
source /usr/local/Ascend/ascend-toolkit/set_env.sh

# 确认环境变量
echo $ASCEND_HOME_PATH    # 应输出 CANN 安装路径
```

---

## 整体流程

```
Step 1: 编译算子工程 → 生成 .run 安装包
Step 2: 安装 .run 包 → 算子注册到 CANN vendor 目录
Step 3: 设置环境变量 → 使 aclnn 接口可用
Step 4: 编译 cppExtension → 生成 Python wheel 包
Step 5: 安装 wheel 包 → 得到 custom_ops Python 模块
Step 6: 运行测试脚本 → 验证正确性与性能
```

---

## Step 1: 编译算子工程

进入 `unique_v3` 工程根目录，执行 `build.sh`：

```bash
cd unique_v3
bash build.sh
```

编译成功后，会在 `build_out/` 目录下生成 `.run` 安装包：

```bash
ls build_out/*.run
# 输出示例：build_out/custom_opp_linux_aarch64.run
```

> **说明**：
> - `build.sh` 会自动读取 `CMakePresets.json` 中的配置（SOC 类型 `ascend910b`、vendor 名称 `customize` 等）。
> - 如需修改 SOC 类型或 vendor 名称，编辑 `CMakePresets.json` 中对应字段即可。
> - 编译产物位于 `build_out/` 目录，如需清理重新编译，删除该目录后重新执行 `build.sh`。

---

## Step 2: 安装 .run 包

执行 `.run` 安装包，将算子安装到 CANN 的 vendor 目录：

```bash
./build_out/custom_opp_linux_aarch64.run
```

安装完成后，终端会输出 `SUCCESS`。

算子文件将被安装到 `$ASCEND_OPP_PATH/vendors/customize/` 目录下，包括：

```
$ASCEND_OPP_PATH/vendors/customize/
├── op_api/          # aclnn 接口动态库 + 头文件
│   ├── lib/
│   │   └── libcust_opapi.so
│   └── include/
│       └── aclnn_unique_v3.h
├── op_proto/        # 算子原型库
│   └── lib/
│       └── libcust_opsproto_rt2.0.so
└── op_impl/         # Tiling + Kernel 实现库
    └── ai_core/
        └── tbe/
            └── op_tiling/
                └── lib/
                    └── libcust_opmaster_rt2.0.so
```

---

## Step 3: 设置环境变量

安装完成后，需要将算子库路径添加到 `LD_LIBRARY_PATH`：

```bash
export LD_LIBRARY_PATH=$ASCEND_OPP_PATH/vendors/customize/op_api/lib/:$LD_LIBRARY_PATH
```

> **建议**：将上述 export 命令添加到 `~/.bashrc` 中，避免每次手动设置。

验证安装是否成功：

```bash
ls $ASCEND_OPP_PATH/vendors/customize/op_api/lib/
# 应能看到 libcust_opapi.so
```

---

## Step 4: 编译 cppExtension（生成 Python wheel 包）

进入 `examples/cppExtension` 目录，使用 `setup.py` 编译生成 wheel 包：

```bash
cd examples/cppExtension
python3 setup.py build bdist_wheel
```

编译成功后，wheel 包生成在 `dist/` 目录下：

```bash
ls dist/
# 输出示例：custom_ops-1.0-cp38-cp38-linux_aarch64.whl
```

> **常见问题**：
> - 如果报 `torch_npu` 找不到，请先确认 `torch_npu` 已正确安装：`python3 -c "import torch_npu; print(torch_npu.__version__)"`。
> - 如果报 ACL 头文件找不到，请确认 Step 3 的环境变量已设置。

---

## Step 5: 安装 wheel 包

```bash
cd dist
pip3 install custom_ops-1.0*.whl
```

或者从 `examples/cppExtension` 目录直接一步安装：

```bash
cd examples/cppExtension
pip3 install dist/custom_ops-1.0*.whl
```

验证安装成功：

```bash
python3 -c "import custom_ops; print('custom_ops imported successfully')"
```

---

## Step 6: 运行测试脚本

回到 `unique_v3` 根目录，执行测试脚本：

```bash
cd unique_v3
python3 test_unique.py
```

或使用 `examples/` 下的测试脚本：

```bash
python3 examples/test_unique.py
```

测试脚本会：
1. 生成随机测试数据（默认 1,000,000 个元素）
2. 在 NPU 上执行 `custom_ops.unique_v3`
3. 在 CPU 上执行 `torch.unique` 作为参考
4. 对比 output、inverse、counts 三项结果是否一致
5. 输出性能对比（NPU 耗时 vs CPU 耗时）

预期输出示例：

```
=== Large Test (1000000 elements) ===
Generating test data...
Warmup data (A) size: 1000000
Test data (B) size: 1000000

=== Warming up NPU with data A (40 iterations) ===
Warmup done!

=== Results ===
NPU unique count: 98213
CPU unique count: 98213

=== Performance ===
NPU time: 1.342 ms
CPU time: 27.156 ms
Speedup: 20.24x

Unique values match: True
Counts match: True
inverse match: True
```

## 快速一键流程

如果环境已就绪，可以使用以下命令一键完成全部步骤：

```bash
# 1. 编译算子工程
cd unique_v3
bash build.sh

# 2. 安装 .run 包
./build_out/custom_opp_*.run

# 3. 设置环境变量
export LD_LIBRARY_PATH=$ASCEND_OPP_PATH/vendors/customize/op_api/lib/:$LD_LIBRARY_PATH

# 4. 编译并安装 cppExtension
cd examples/cppExtension
python3 setup.py build bdist_wheel
pip3 install dist/custom_ops-1.0*.whl

# 5. 运行测试
cd ../..
python3 test_unique.py
```

## 调用示例

安装完成后，在任意 Python 脚本中即可调用：

```python
import torch
import torch_npu
import custom_ops

# 准备数据
x = torch.tensor([3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5], dtype=torch.float32).npu()

# 调用算子
output, unique_cnt, inverse, counts = custom_ops.unique_v3(x, True, True)

cnt = unique_cnt.item()
print(f"唯一值: {output[:cnt].cpu().tolist()}")         # [1, 2, 3, 4, 5, 6, 9]
print(f"反向索引: {inverse[:len(x)].cpu().tolist()}")    # output[inverse[i]] == x[i]
print(f"计数: {counts[:cnt].cpu().tolist()}")             # [2, 1, 2, 1, 3, 1, 1]
```

## 卸载

如需卸载已安装的算子：

```bash
# 卸载 cppExtension wheel 包
pip3 uninstall custom_ops -y

# 移除 vendor 目录中的算子文件
rm -rf $ASCEND_OPP_PATH/vendors/customize
