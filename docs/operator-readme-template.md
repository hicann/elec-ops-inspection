# 算子 README 模板

本模板用于新增或重写 `elec-ops-inspection` 算子目录下的 README。目标是让使用者能够理解算子用途、确认接口约束、完成构建运行，并复核精度与性能证据。

## 使用规则

1. 将模板复制到算子目录的 `README.md`，替换所有 `<...>` 占位符。
2. 保留与算子实际内容相关的章节；不适用的可选章节应删除，不要保留空标题。
3. 接口名称、输入输出顺序、dtype、shape、属性默认值应与 OpDef/JSON、tiling、kernel 和调用示例一致。
4. 命令应从仓库根目录或明确标注的工作目录执行，避免本地绝对路径和未说明的环境变量。
5. 精度、性能、显存、吞吐和业务收益必须附测试环境、输入规模、比较基线和复现命令。没有证据时写“待验证”，不要填写估算数据。
6. 不提交账号、令牌、私有数据、设备地址、内部链接、构建产物或本地日志。
