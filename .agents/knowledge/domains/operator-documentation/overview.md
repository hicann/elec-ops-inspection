# Operator Documentation And Evidence Review

## Scope

Use this domain for tasks that preserve reusable context about
`elec-ops-inspection` operator documentation, local Codex skills, benchmark
evidence expectations, and PR-ready review notes.

## Goals

- Keep future Codex sessions oriented without rereading unrelated files.
- Separate durable project context from task-specific scratch work.
- Record evidence requirements before claiming accuracy, performance, hardware
  support, or production readiness.
- Keep the knowledge base public and reviewable.

## Common Inputs

- Root `README.md`.
- Operator README or usage documents under `optimized_transducer/` and
  `unique_v3/`.
- `.agents/skills/*/SKILL.md` and nearby references.
- User-provided benchmark logs, accuracy reports, or PR diffs.

## Common Outputs

- A small status update in `projects/elec-ops-inspection/current-status.md`.
- A durable decision in `projects/elec-ops-inspection/decisions.md`.
- A new template or checklist when repeated tasks need structure.
- A PR-ready summary that distinguishes facts from required follow-up evidence.
