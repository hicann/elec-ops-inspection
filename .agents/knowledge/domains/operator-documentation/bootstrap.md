For a new Codex session working on repository context, skill authoring, or
operator documentation:

1. Read `.agents/knowledge/registry.yaml`.
2. Read `projects/elec-ops-inspection/project-summary.md`.
3. Read `projects/elec-ops-inspection/current-status.md`.
4. Read `projects/elec-ops-inspection/entrypoints.md`.
5. Read this domain's `evidence-rules.md` when the task involves claims about
   accuracy, performance, hardware, reproducibility, or PR readiness.

Do not load unrelated knowledge packages. If a task needs fresh facts, inspect
the live repository files and treat them as the source of truth.
