# elec-ops-inspection Project Summary

## Project Positioning

`elec-ops-inspection` is a CANN community repository for power equipment
inspection operators and related Ascend/CANN documentation.

## Current Repository Areas

- `optimized_transducer/`: RNN-T related operator implementation and docs.
- `unique_v3/`: high-performance unique/deduplication operator implementation
  and docs.
- `.agents/skills/`: repository-local Codex skills.
- `.agents/knowledge/`: repo-local knowledge scaffold for durable context.
