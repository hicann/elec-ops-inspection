# PR Description Template

Use this template when preparing a PR for `cann/elec-ops-inspection`.

```markdown
## Summary

- Add or update:
- Inspection scenario:
- Ascend/CANN value:

## Technical Notes

- Public interface:
- Host/kernel path:
- Supported dtypes and shapes:
- Main optimization:

## Validation

- Accuracy:
- Performance:
- Example or build command:

## Known Limits

- Hardware/software constraints:
- Unsupported shapes or dtypes:
- Follow-up items:
```

Keep unverified data out of the PR description. If a number is not measured in the current environment, describe it as a required validation item instead of a result.
